RITMO — PACOTE DE LEMBRETES ÀS 05:00

ATENÇÃO
Este pacote prepara o Ritmo para receber notificações push. Elas NÃO funcionarão só por enviar os arquivos ao GitHub: é preciso criar e configurar um projeto Firebase e publicar a função agendada. O envio automático diário usa Cloud Scheduler, que exige o plano Blaze/conta de faturamento. Como você é menor de idade, peça a um responsável para criar/administrar o projeto e avaliar qualquer cobrança. Não cadastre cartão nem ative faturamento sozinho.

O QUE FOI PREPARADO
- Área “Lembretes de treino” no Perfil: dias, tipo, distância, pace e botões para ativar/desativar.
- Serviço de notificações web do Firebase.
- Função de servidor programada para 05:00 no fuso de Fortaleza.
- Regras do Firestore para cada usuário acessar apenas sua configuração.

PARTE 1 — CRIAR O PROJETO (com um responsável)
1. Entre em https://console.firebase.google.com/ e crie um projeto chamado Ritmo.
2. Adicione um aplicativo do tipo Web (ícone </>) e registre-o.
3. Copie a configuração do app Web mostrada pelo Firebase.
4. No menu Authentication > Sign-in method, habilite Anonymous.
5. Em Firestore Database, crie o banco de dados.
6. Em Configurações do projeto > Cloud Messaging, encontre Web Push certificates e gere um par de chaves VAPID. Copie a chave pública.
7. Em Authentication > Settings > Authorized domains, confirme que app31112026-boop.github.io está autorizado.

PARTE 2 — PREENCHER AS CONFIGURAÇÕES DO SITE
1. Abra firebase-config.js.
2. Substitua os valores de exemplo pelos valores da configuração do aplicativo Web. Não altere os nomes dos campos.
3. Coloque a chave pública VAPID em RITMO_VAPID_KEY.
4. Abra firebase-messaging-sw.js e repita nele os mesmos valores públicos do Firebase (apiKey, authDomain, projectId, storageBucket, messagingSenderId e appId).
5. Salve os dois arquivos.

A configuração Web do Firebase e a chave VAPID pública não são senhas. Nunca publique chave privada VAPID, chave de conta de serviço, senha ou arquivo de credenciais administrativas.

PARTE 3 — PUBLICAR O SERVIDOR DE NOTIFICAÇÕES
Esta etapa exige computador e ajuda do responsável. O projeto inclui a pasta firebase.
1. Instale Node.js e Firebase CLI no computador, seguindo a documentação oficial: https://firebase.google.com/docs/cli
2. Abra o terminal dentro da pasta firebase deste pacote.
3. Faça login: firebase login
4. Associe o projeto: copie .firebaserc.example para .firebaserc e substitua SEU_PROJECT_ID pelo ID real do projeto.
5. Entre na pasta functions e execute: npm install
6. Volte à pasta firebase e publique: firebase deploy --only firestore:rules,functions
7. Se o Firebase pedir para ativar faturamento/Blaze, pare e peça ao responsável para revisar custos e decidir. Não ative sem autorização.

PARTE 4 — ENVIAR OS ARQUIVOS AO GITHUB
Na raiz do repositório Ritmo-corrida, substitua os arquivos do app pelos arquivos deste pacote:
- index.html
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png
E adicione também:
- firebase-config.js
- firebase-messaging-sw.js
Não envie a pasta firebase para a raiz pública do site por engano; ela é usada no computador para publicar as regras e a função. Guarde-a com segurança. Depois faça commit na branch main e aguarde o GitHub Pages atualizar.

PARTE 5 — ATIVAR NO CELULAR
1. Abra o Ritmo no Samsung Internet usando HTTPS.
2. Vá em Perfil > Lembretes de treino.
3. Marque os dias que realmente têm treino na planilha do treinador.
4. Informe tipo, distância e ritmo planejado.
5. Toque em “Ativar notificações” e permita as notificações do navegador.
6. Teste primeiro com uma notificação de teste pelo Firebase Console. O lembrete agendado será enviado às 05:00 nos dias escolhidos.

IMPORTANTE
- A notificação é um lembrete, não uma prescrição de treino. Use apenas os detalhes definidos pelo seu treinador.
- O navegador/aparelho precisa permitir notificações; modo economia de bateria, permissões e configurações do sistema podem afetar a entrega.
- O Firebase pode gerar custos no plano Blaze. O preço de Cloud Scheduler e demais serviços deve ser conferido pelo responsável antes de ativar: https://firebase.google.com/docs/functions/schedule-functions e https://firebase.google.com/docs/projects/billing/firebase-pricing-plans
- Se quiser desligar, use “Desativar” dentro do Ritmo e também bloqueie a permissão nas configurações do navegador se desejar.
- Este pacote é uma integração inicial. As configurações reais do seu projeto Firebase ainda precisam ser preenchidas e o backend publicado; portanto, não está ativo automaticamente neste momento.
